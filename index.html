🚨 徒步前必读

关键因素：天气！
✓ 晴朗/多云 + 温度15℃以上 = 可以去
✗ 阴天/小雨 = 能见度低，放弃
✗ 中雨以上 = 危险，绝对不去
📅 建议：根据9月20日气象预报决定

上午

12:00 退房 丽枫酒店

📍 安顺 → 贵阳（约2小时车程）

下午

15:00 入住 贵阳十里河港福朋喜来登

🥾 铜鼓荡-牛倒岩-万峰顶徒步 推荐（天气好）

📍 位置：荔波县大七孔景区附近
📏 全程：12-15公里 | 垂直爬升：约800米
⏱️ 耗时：4-6小时（含休息）
🎯 难度：中等强度

路线概览

铜鼓荡村出发 → 原始森林 → 牛倒岩（打卡点，远眺喀斯特峰林） → 万峰顶（制高点，360°景观）

徒步前检查清单

  • 防滑登山鞋（必须！）
  • 登山杖2根
  • 登山包+防水套
  • 充足的水（每人2L+）和干粮
  • 防晒霜、防蚊液
  • 雨衣/防雨套
  • 急救包、手机充电宝
  • 离线地图/GPS设备

重要提示

⏰ 早上6-7点出发，确保下午3点前下山
📱 手机信号不全，提前下载离线地图
🌧️ 雨天路滑，不建议走
🌫️ 阴天能见度低，价值不大
👥 2人登山，注意相互照应

💡 实用贴士

📦 10月贵州必备物品

  • 🌧️ 雨具：10月降雨频繁（每2天1次），必须带伞+雨衣
  • 👕 衣物：长袖为主，早晚温差6℃，备薄外套
  • 👟 鞋子：防滑登山鞋（徒步/溯溪必须），快干鞋（浆板）
  • 🧴 防晒防蚊：SPF50+防晒霜，防蚊液（高原蚊子狠）
  • 💊 药品：晕车药、感冒药、肠胃药、创可贴
  • 🎒 背包：徒步用登山包（40-50L），日常用20-30L

🗺️ 关键距离与时间

  • 贵阳 → 兴义：约180km，车程3小时
  • 兴义 → 安顺：约150km，车程1.5小时
  • 安顺 → 贵阳：约120km，车程2小时
  • 贵阳市区 → 荔波大七孔：约80km，车程1.5小时
